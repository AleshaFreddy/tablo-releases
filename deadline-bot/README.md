# Бот дедлайнов

Telegram-бот для технического канала группы. В личке с ботом добавляешь дедлайн, а бот пишет в канал:

- 🆕 объявление сразу после добавления;
- ⏰ напоминание за **неделю**, за **2 суток**, за **сутки** и за **12 часов**.

Если дедлайн добавлен, когда до него осталось, например, 3 дня, напоминание «за неделю» не придёт, остальные придут по расписанию. Если бот был выключен и пропустил несколько напоминаний, после включения он пришлёт одно, самое свежее, без пачки старых.

## Как добавить дедлайн

Напиши боту `/new` и ответь на вопросы:

1. **Название**: по какой работе дедлайн.
2. **Ссылка** на файл или сайт. Можно нажать «Без ссылки».
3. **Ответственные**: отметь людей кнопками (можно несколько). Если нужного человека нет в списке, пришли сообщение `Имя @username`, и он добавится.
4. **Дата**: выбери в календаре или напиши `25.11`, `25.11.2026` или сразу `25.11 18:00`.
5. **Время**: выбери час и минуты кнопками или напиши `18:30`.
6. Проверь карточку и нажми «Сохранить».

Остальные команды:

| Команда | Что делает |
|---|---|
| `/list` | актуальные дедлайны |
| `/delete` | удалить дедлайн (можно с сообщением «отменён» в канале) |
| `/people` | список людей, удаление из списка |
| `/addperson Имя @username` | добавить человека |
| `/cancel` | прервать ввод |

Тот, кто напишет боту `/start`, сам попадает в список людей.

**Кто может пользоваться ботом.** По умолчанию только подписчики канала: бот проверяет это сам. Чтобы ограничить список сильнее, перечисли Telegram ID в `ALLOWED_USER_IDS`.

## Запуск

Боту нужен компьютер, который работает постоянно: VPS, домашний сервер, Raspberry Pi и т.п. Всё время уходит на опрос Telegram, вебхук и белый IP не нужны.

### 1. Настройки

```bash
cp .env.example .env
```

В `.env` впиши `BOT_TOKEN` (токен от @BotFather). **Не коммить `.env` и не выкладывай токен**: файл уже в `.gitignore`.

`CHANNEL_ID` можно не заполнять. После запуска перешли боту в личку любой пост из канала: бот проверит, что он там админ, и запомнит канал. Можно и сразу указать ID канала (`-100…`) или `@username` публичного канала.

Часовой пояс по умолчанию `Europe/Moscow` (`TZ_NAME`).

### 2a. Docker (проще всего)

```bash
docker compose up -d --build
docker compose logs -f
```

База хранится в `./data/deadlines.db`.

### 2b. Без Docker

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

Для автозапуска есть пример unit-файла systemd: `deadline-bot.service`.
