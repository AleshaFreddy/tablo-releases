# Бот дедлайнов

Telegram-бот для технического канала группы. В личке с ботом добавляешь дедлайн, а бот пишет в канал:

- 🆕 объявление сразу после добавления;
- ⏰ напоминание за **неделю**, за **2 суток**, за **сутки** и за **12 часов**.

Если дедлайн добавлен, когда до него осталось, например, 3 дня, напоминание «за неделю» не придёт, остальные придут по расписанию. Если бот был выключен и пропустил несколько напоминаний, после включения он пришлёт одно, самое свежее, без пачки старых.

## Как добавить дедлайн

Напиши боту `/new` и ответь на вопросы:

1. **Название**: по какой работе дедлайн.
2. **Категория**: «Внеучебка», «РАНХиГС», «Магистратура» или новая (просто пришли её название).
3. **Ссылка** на файл или сайт. Можно нажать «Без ссылки».
4. **Ответственные**: отметь людей кнопками (можно несколько). Если нужного человека нет в списке, пришли сообщение `Имя @username`, и он добавится.
5. **Дата**: выбери в календаре или напиши `25.11`, `25.11.2026` или сразу `25.11 18:00`.
6. **Время**: выбери час и минуты кнопками или напиши `18:30`.
7. Проверь карточку и нажми «Сохранить».

Остальные команды:

| Команда | Что делает |
|---|---|
| `/list` | актуальные дедлайны, под списком кнопки фильтра по категориям |
| `/list Внеучебка` | дедлайны одной категории |
| `/category` | сменить категорию дедлайна, добавленного через бота |
| `/categories`, `/addcategory Название` | список категорий |
| `/delete` | удалить дедлайн (можно с сообщением «отменён» в канале) |
| `/people` | список людей, удаление из списка |
| `/addperson Имя @username` | добавить человека |
| `/iam Имя` | «в таблице я записан(а) как Имя»: бот будет упоминать тебя по этому имени |
| `/sync` | перечитать Google-таблицу |
| `/alias имя @username` | соответствие имени из таблицы и Telegram |
| `/cancel` | прервать ввод |
| `/help` | гайд по боту с разделами (кнопки) |

Тот, кто напишет боту `/start`, сам попадает в список людей.

**Кто может пользоваться ботом.** По умолчанию только подписчики канала: бот проверяет это сам. Чтобы ограничить список сильнее, перечисли Telegram ID в `ALLOWED_USER_IDS`.

## Категории

У каждого дедлайна может быть категория. В канале она показывается хэштегом (`#Внеучебка`, `#РАНХиГС`, `#Магистратура`): нажмите на хэштег, и Telegram покажет все посты с ним. В `/list` под списком есть кнопки, которые фильтруют дедлайны по категории. Список категорий по умолчанию задаётся в `CATEGORIES`, дальше его меняют командами `/categories` и `/addcategory`.

## Дедлайны из Google-таблицы

Бот читает лист **«Все дедлайны»** таблицы «Калейдоскоп событий» (ссылка в `SHEET_URL`) раз в 10 минут. По каждой строке с датой в «Дедлайн» он шлёт такие же напоминания: за неделю, 2 суток, сутки и 12 часов. Кроме того, он пишет в канал, когда в таблице появляется новый дедлайн или переносится старый. При первом чтении таблицы бот ничего не объявляет, чтобы не завалить канал.

### Как вести лист «Все дедлайны»

**Одна строка - один дедлайн.** Если у мероприятия несколько сроков (регистрация, статья), заведите несколько строк с одним названием и разным «Этапом».

| Колонка | Что писать | Бот |
|---|---|---|
| Мероприятие | название | ✔ обязательно |
| Тип | конференция, олимпиада, конкурс... (выпадающий список) | показывает |
| Категория | Внеучебка, РАНХиГС, Магистратура (выпадающий список, можно вписать свою) | хэштег и фильтр |
| Этап | регистрация, заявка, подача статьи... | показывает рядом с названием |
| Дедлайн | **только дата и время**: `25.11.2026 18:00`. Не знаете дату - оставьте пусто | ✔ напоминания |
| Дней осталось | считается само | - |
| Статус | планируем / в работе / подано / сдано / не участвуем | при «подано», «сдано», «не участвуем» напоминаний нет |
| Ответственные | имена через запятую, всегда одинаково | упоминает (`/alias`) |
| Ссылка | сайт, форма, файл | показывает |
| Ориентир по срокам | для ежегодных событий без точной даты: «обычно в мае» | - |
| Даты мероприятия | когда само событие | показывает |
| Комментарий | заметки, ссылки на посты | показывает |
| Что даёт, Предмет, Организатор, Описание, Откуда | справочно | - |

Строки подсвечиваются сами: красным - до дедлайна меньше 2 суток, жёлтым - меньше недели, серым - дедлайн прошёл, зелёным - подано или сдано. Чтобы пересортировать лист после добавления строк, откройте фильтр в заголовке «Дедлайн» и выберите «Сортировка А → Я».

Бот понимает и старый лист «26/27» (колонки «Название мероприятия», «Ближайший дедлайн», «(со)участие»...), если когда-нибудь понадобится вернуться к нему.

В колонке «Ответственные» пишите имена всегда одинаково: **Айсаар, Настя, Оля, Сеня, Лёша**. Каждый один раз пишет боту `/iam Сеня` (своё имя), и после этого бот упоминает его в канале. Для человека, который не пользуется ботом, можно задать `/alias Имя @username`.

**Доступ.** Бот читает таблицу без входа в Google, поэтому нужно одно из двух:
- «Настройки доступа» → «Все, у кого есть ссылка» → «Читатель»;
- или «Файл» → «Поделиться» → «Опубликовать в интернете» → нужный лист → CSV, и эту ссылку указать в `SHEET_URL`.

Команды: `/sync` перечитывает таблицу сразу и показывает проблемные строки, `/alias` задаёт соответствия имён.

## Запуск

Боту нужен компьютер, который работает постоянно: VPS, домашний сервер, Raspberry Pi и т.п. Всё время уходит на опрос Telegram, вебхук и белый IP не нужны.

### 1. Настройки

```bash
cp .env.example .env
```

В `.env` впиши `BOT_TOKEN` (токен от @BotFather). **Не коммить `.env` и не выкладывай токен**: файл уже в `.gitignore`.

`CHANNEL_ID` можно не заполнять. После запуска перешли боту в личку любой пост из канала: бот проверит, что он там админ, и запомнит канал. Можно и сразу указать ID канала (`-100…`) или `@username` публичного канала.

Часовой пояс по умолчанию `Europe/Moscow` (`TZ_NAME`).

### 2a. Docker (проще всего)

```bash
docker compose up -d --build
docker compose logs -f
```

База хранится в `./data/deadlines.db`.

### 2b. Без Docker

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

Для автозапуска есть пример unit-файла systemd: `deadline-bot.service`.
