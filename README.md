# Табло

Табло прибытия транспорта: автобусы рядом с домом (Яндекс Карты), электрички (Яндекс Расписания) и поездка с уведомлениями о станциях. Есть версии для Android, часов Wear OS и Windows.

Здесь лежат готовые версии для друзей и знакомых. Последняя версия всегда на странице [Releases](../../releases/latest).

## Установка

**Android.** Скачай `Tablo-<версия>-beta.apk` и открой его. Android один раз спросит разрешение на установку из браузера или Telegram - разреши. Дальше «Табло» само сообщит о новой версии и обновится кнопкой «Обновить» в настройках.

**Часы Wear OS.** Первый раз приложение `Tablo-Watch-<версия>.apk` ставится на часы через Bugjaeger (инструкция в описании выпуска). Потом часы обновляются сами: новая версия приходит с телефона, на часах появляется вкладка «Обновить».

**Windows.** Скачай `Tablo-<версия>-beta-windows.zip`, распакуй и запусти `.exe`. Если Windows покажет «Windows защитил ваш компьютер», нажми «Подробнее», потом «Выполнить в любом случае».

## Для электричек

Нужен свой бесплатный ключ API Яндекс Расписаний: developer.tech.yandex.ru, «API Яндекс.Расписаний». Ключ вставляется в «Табло» на вкладке «Электрички».
